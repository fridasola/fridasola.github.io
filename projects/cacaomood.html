🍫 CacaoMood — Implémentation d'une solution RAG

Rôle : Développeuse bases de données & Ingénieure IA · Temps estimé : 45 minutes

Contexte & Objectif

CacaoMood est une plateforme e‑commerce et holistique. Objectif : créer un assistant virtuel recommandant des rituels de cacao en s'appuyant uniquement sur le catalogue produit (grounding strict) pour éviter les hallucinations.

Étapes clés

  1. Infrastructure relationnelle — Tables produit + colonne vectorielle native VECTOR(1536) pour les embeddings.
  2. Sécurité & modèles externes — Identity Managed pour Azure OpenAI ; déclaration d'un MODEL externe pour embeddings.
  3. Vectorisation par lots — Script T‑SQL robuste avec batching, pause et retry en cas de rate‑limit.
  4. Indexation DiskANN — Index vectoriel ANN (DiskANN) pour recherche rapide.
  5. Procédure stockée RAG — dbo.AskCacaoQuestion : retrieval (VECTOR_SEARCH), augmentation (FOR JSON) et génération via sp_invoke_external_rest_endpoint.

Extraits SQL (principaux éléments)

Création des tables et colonne vectorielle :

-- Création des tables
CREATE TABLE dbo.ProductBenefits (
    BenefitID INT IDENTITY(1,1) PRIMARY KEY,
    BenefitName VARCHAR(100) NOT NULL,
    TargetMood VARCHAR(100) NOT NULL
);

CREATE TABLE dbo.CacaoProducts (
    ProductID INT IDENTITY(1,1) PRIMARY KEY,
    ProductName NVARCHAR(150) NOT NULL,
    OriginCountry NVARCHAR(100) NOT NULL,
    Description NVARCHAR(MAX) NOT NULL,
    Price DECIMAL(5,2) NOT NULL,
    BenefitID INT FOREIGN KEY REFERENCES dbo.ProductBenefits(BenefitID),
    CacaoVector VECTOR(1536) NULL
);

Vectorisation batch (extrait) :

DECLARE @batchSize INT = 30;
WHILE @rowsUpdated > 0
BEGIN
  UPDATE TOP (@batchSize) p
  SET p.CacaoVector = AI_GENERATE_EMBEDDINGS(
    p.ProductName + ' | Origine: ' + p.OriginCountry + ' | Bienfaits: ' + b.BenefitName + ' | ' + p.Description
    USE MODEL my_embedding_model
  )
  FROM dbo.CacaoProducts p
  INNER JOIN dbo.ProductBenefits b ON p.BenefitID = b.BenefitID
  WHERE p.CacaoVector IS NULL;
END;

Création de l'index DiskANN :

CREATE VECTOR INDEX IX_CacaoProducts_CacaoVector
ON dbo.CacaoProducts(CacaoVector)
WITH (METRIC = 'cosine', TYPE = 'DISKANN');

Procédure stockée RAG (résumé) : vectoriser la question, récupérer TOP 3 via VECTOR_SEARCH, packer le contexte en JSON et appeler l'API Azure OpenAI avec sp_invoke_external_rest_endpoint. Gestion d'erreurs et messages système pour ancrage strict.

Tests & Recette

Tests exemples inclus (exécuter dbo.AskCacaoQuestion avec des questions clients). Résultat attendu : sélection pertinente des produits (Aurore Énergisante, Sérénité du Soir) et réponses ancrées, concises et non‑hallucinées.

Points d'attention & bonnes pratiques

  • Utiliser identity managed pour éviter stockage de secrets.
  • Imposer temperature basse (0.3) et instructions système strictes pour le grounding.
  • Mettre en place monitoring des latences et quotas Azure OpenAI (retry/backoff).
  • Valider les données catalogue (prix, disponibilité) avant injection dans le prompt.

Compétences : SQL avancé, embeddings, index vectoriel, RAG, Azure OpenAI
