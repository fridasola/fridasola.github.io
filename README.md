Portfolio pour Emily NOLE (fridasola)

Installation locale:
1. Placer les fichiers dans un dépôt Git nommé `fridasola.github.io` (recommandé pour GitHub Pages utilisateur) ou dans un repo au choix.
2. Ajouter la photo de profil dans `assets/profile.svg`.
3. Remplacer les placeholders de projets dans `index.html` par vos titres, descriptions, liens et images.
4. Commit et push sur GitHub.

Publication (GitHub Pages):
- Pour une page utilisateur: créez un repo nommé `fridasola.github.io` et poussez la branche main. Le site sera disponible sur `https://fridasola.github.io/`.
- Pour un repo projet: activez GitHub Pages dans les settings du repo.

Besoin d'aide: envoyez la photo et les détails des 3 projets (titre, description, repo/live, techs).
